# AI 生成变式题 — 图片质量审查

范围：`generated/` 下全部 268 道变式题（229 道有 `figure.svg`，2 道只有选项图 `choice-*.svg`，37 道无图）。
方法：

1. 用 Chrome 无头渲染每个 SVG，用 DOM 几何检查元素是否超出 viewBox、文字是否互相重叠、按页面实际显示尺寸（`max-h 220px`，`max-w ≈ 600px`）换算的最小字号，以及 `question.json` 的宽高比与 viewBox 是否一致；
2. 把 231 张渲染图拼成拼图，逐张人工看过；可疑的再对照 `compare.png` 原题与题干确认。
