# 方案 A · Anthropic Style — 方案说明

> 原型：`docs/design/prototypes/anthropic/` · 截图：`docs/design/screenshots/anthropic-*.png` · 设计系统 token：`docs/design/tokens/anthropic-style.tokens.json`
>
> 页面结构和交互改动与方案 C 相同（见 `plan-c.md` §6）；本文只写 A 的视觉语言与组件差异。若选定 A，按 `plan-c.md` 的文件清单与验收标准实施，把 §2–§5 的取值换成下表。

## 1. 设计理念

**“暖纸面上读题，像一本安静的练习册。”** 题干用衬线体，标签与按钮用无衬线体；主按钮是墨色胶囊；强调色每屏最多一处；没有阴影、没有 hover 位移，只有颜色过渡。适合重视阅读体验、希望界面“像书不像游戏”的取向。

## 3. 组件差异（相对方案 C）

- **按钮**：主 = 墨底纸字胶囊 52px；次 = 1px 墨色描边胶囊；危险 = 错误红描边 + 红字；所有文字 Inter Tight 500。
- **题号**：48px **圆角方块**（8px），4 列。当前题（考试中）= 墨底纸字（反色表达“当前”）；有状态时当前题 = 2px 墨色 outline。对 = olive 底墨字 19px/700（大字号以满足 3:1）；错 = coral 底 + 红边；跳过 = 虚线。
- **选项**：白卡 2px 边；字母徽章 44px，默认是 1px 墨色描边圆，选中变墨底（反色）。
- **讲解面板**：白卡 8px 圆角，标题 “Why the answer is B”（Inter Tight 700），正文衬线 20px；按钮 “Write it again”（次）/ “Hide”（主）。
- **反馈**：整条横幅（8px 圆角），对 = olive 底，错 = coral 底，Inter Tight 600 20px。
- **计时**：白卡内 28px 数字 + 6px 墨色进度条。
- **结果分数卡**：Slate 深色 16px 圆角卡，56px 分数，三列 right / wrong / skipped 计数；下方一段衬线说明计分规则。
- **选卷页**：按年份分行的列表，每行左侧年份，右侧白色系列卡；系列筛选胶囊。

## 4. 适合 / 风险

- 适合：家长视角最舒服，阅读体验最好，品牌感“可信、安静”。
- 风险：对 6–7 岁孩子略沉静；衬线体在小屏上需要注意字号；olive 上白字对比不足，所以对的状态一律用墨色字。
