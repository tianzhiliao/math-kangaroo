# 方案 B · Cursor Style — 方案说明

> 原型：`docs/design/prototypes/cursor/` · 截图：`docs/design/screenshots/cursor-*.png` · 设计系统 token：`docs/design/tokens/cursor-style.tokens.json`
>
> 页面结构和交互改动与方案 C 相同（见 `plan-c.md` §6）；本文只写 B 的视觉语言与组件差异。若选定 B，按 `plan-c.md` 的文件清单与验收标准实施，把 §2–§5 的取值换成下表。

## 1. 设计理念

**“一个安静、专注的工具。”** 全站字重 400，层级只靠字号和文字透明度（100 / 60 / 40%）；容器是 4px 方角，可点的东西是胶囊；边框几乎不可见（2.5%–10%）；唯一强调色橙 `#f54e00` 只标“当前位置”和计时。数字、题号、计时一律等宽字体。顶栏 + 侧栏的工具型布局。

## 3. 组件差异（相对方案 C）

- **布局**：所有页面有 56–64px 顶栏，左侧面包屑 `Math Kangaroo / Level P · Brazil 2020`；考试页把计时（等宽 22px）放在顶栏中间，顶栏底边 2px 进度线；Leave / Submit 在顶栏右侧。
- **按钮**：主 = 墨底浅字胶囊 52px；次 = 透明 + 20% 内描边胶囊；危险 = 红色内描边 + 红字。听题按钮是带文字的胶囊 “Listen”。
- **题号**：46px 4px 方块，等宽数字；当前题 = 2px 橙色外圈；对 = 绿实心白字；错 = 浅红底 + 红内描边。
- **选项**：4px 方角卡，卡片台阶底色；选中 = 2px 墨色内描边 + 深一档底；揭晓后徽章换成 ✓ / ×，右侧标签 `B · right answer`。
- **讲解面板**：反馈句（× Not quite…）与讲解合并在一个卡片台阶面板里；算式用等宽字体小色块 `60 − 52 = 8`；按钮 “↻ Write again” / “Hide ↑”。
- **变式题**：折叠行 `变式题 · Try a similar question ↓`，展开后带内描边的面板。
- **选卷页**：表格（年份 / 系列 / 题数 / 时长 / Start →），只画横线，数字等宽；顶部分段控件 `All · 16 / Felix · 10 / Level P · 2 / Grade 1–2 · 4`。
- **结果**：侧栏 52px 分数 + 一张横线表（起始分 24、+59、−4、0）。

## 4. 适合 / 风险

- 适合：最简洁、信息密度最高，家长/老师复盘时也好用。
- 风险：全细字重 + 低对比层级，对低龄孩子“哪里能点”的提示最弱；60% 次要文字在浅底上约 4.1:1，略低于 AA，需要在实施时提到 65%。
